## Plan 2 outcome (2026-11-03)

Built: Wibey and fake providers (fixed model `gpt-6.1-sol`), three batches (wording, story, flow), injection-resistant
prompts (v4), line-by-line verbatim grounding, cross-batch dedupe, file cache, `--ai` CLI, Ask the coach, and a
human-reviewed cache that the static demo replays offline (normal builds never touch the network).

Verified by the round 3 committee (`docs/reviews/2026-11-03-committee-review-round-3.md`): the AI finds problems code
cannot (placeholder rows, missing answers, a leading question). Fixed in the same pass: duplicate findings, competing
rewrites of one text, invented facts (now `[bracketed]` for the researcher), rewrites that changed question type,
overclaims in the UI, and weak provenance.

Known limits, stated plainly in the product:
- Absence findings (for example "never says how feedback is used") can only quote the stem or greeting as evidence.
- Two fixes that rewrite overlapping words cannot both show on the phone: code-made fixes go first, the card of the
  loser says so. A merged rewrite is a later feature.
- The demo replays saved model answers; it does not call the model live.
