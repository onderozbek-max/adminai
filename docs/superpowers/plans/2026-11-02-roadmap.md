# SurveyCoach Build Roadmap

Spec: `../specs/2026-11-02-survey-coach-design.md`. Rubric: `../../rubric/mmc-survey-rubric-v2.md`.
The spec spans several subsystems, so it's built as a sequence of plans. Each plan
ends with working, tested software and gets its own detailed plan file before work starts.

| Plan | Delivers | Working software at the end | Blocked by |
|---|---|---|---|
| 0. Spikes | Done: R1, R1b, R1c (live generic crawl of posthalloween26), R2 (Wibey vision via file output). | Findings notes in `docs/spikes/` | Nothing |
| 1. Review engine (DONE 2026-11-02, 121 tests) | Survey snapshot model, rubric loader with the sum-to-100 check, deterministic checks (text, time, phone, images), timing model, scoring and readiness | `python -m surveycoach review fixtures/boxer-briefs.json` prints a scored review | Nothing |
| 2. AI judge | `LlmProvider` (Wibey and fake), judge prompts and schemas, caching, rewrite suggestions, Ask the coach | The same command adds AI findings and three rewrites | R2 result |
| 3. Backend | FastAPI, SQLite, surveys, versions, jobs, SSE progress, re-check diff | API tests pass. Paste a fixture, then stream a review | Plans 1 and 2 |
| 4. Frontend core | Living Design app: Home, reading moment, review workspace (rail, phone, coach, which version is better, copy) | Usable end to end with fixture surveys | Plan 3 |
| 5. Reader | `CrawlReader` per reader design v2: Survey Zoo first, then the page loop, strategy registry, repair rules, vision fallback, nested sections and loops, image capture, extractors, replica, coverage, live-data containment | The Zoo crawls end to end offline; then one approved, tagged live crawl of a RedJade link | Plan 3 (Zoo work can start in parallel with Plan 1) |
| 6. Workflow | Versions, sign-off packet export, Guidelines library and glossary | The full v1 loop | Plan 4 |
| 7. Wow and polish | Play as a member, device and accessibility toggles, suggested crop, motion, accessibility pass, E2E suite | v1 complete | Plan 6 |
| 8. v1.5 | Performance import, predicted vs. actual | Learned cards and the coach accuracy panel | Real launch data |
